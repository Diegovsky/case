# Mode (Moda)

The mode is the simplest measure of central tendency. It is the value that appears most frequently in a dataset.

## Types of Mode
- **Unimodal**: There is one single value that repeats the most.
- **Bimodal**: There are two values that repeat with the same maximum frequency.
- **Multimodal**: There are three or more values that repeat with the same maximum frequency.
- **Amodal**: No value repeats; every value appears only once.

## Example
Dataset: $\{2, 3, 3, 4, 4, 4, 5, 8, 9\}$
The value **4** appears three times. The mode is **4**.

💡 **ENEM Tip:** The mode is particularly useful for categorical data (e.g., "Which color of car is most common in this parking lot?").
