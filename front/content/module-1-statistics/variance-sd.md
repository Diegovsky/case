# Variance and Standard Deviation

These measures tell us how "consistent" or "regular" a set of data is.

## Conceptual Understanding
Rather than focusing on complex calculations, ENEM often tests your ability to interpret these values:

- **Low Standard Deviation**: The data points are close to the mean. The dataset is **consistent, homogeneous, or regular**.
- **High Standard Deviation**: The data points are spread far from the mean. The dataset is **volatile, heterogeneous, or irregular**.

## Quick Definitions
- **Variance ($\sigma^2$):** The average of the squared differences from the Mean.
- **Standard Deviation ($\sigma$):** The square root of the variance. It returns the measure to the original units of the data.

💡 **ENEM Tip:** If a question asks which athlete is "more regular" or which machine is "more precise," look for the one with the **lowest standard deviation**.
